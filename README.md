# KHS Impex

This is a modern web application built with [Next.js](https://nextjs.org/) for KHS Impex.

## Features

- **Manufacturing**: Showcase of manufacturing capabilities and processes.
- **Technology**: Overview of the technological infrastructure and innovations.
- **Sustainability**: Details about sustainable practices and commitments.
- **Quality**: Information regarding quality control and standards.
- **Contact & Enquiries**: Integrated with Nodemailer for efficient email communication.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Notifications:** React Hot Toast
- **Email:** Nodemailer
- **Language:** TypeScript

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

The project follows the standard Next.js App Router structure. Key pages are located in `src/app/`:

- `/manufacturing`
- `/technology`
- `/sustainability`
- `/quality`
